# Merge Objects Asset Folder

This folder is intended for storing the PNG assets of merge objects (boxes/items) across tiers.

## Naming Convention
- Name your PNG files according to their tier:
  - `tier_1.png`
  - `tier_2.png`
  - `tier_3.png`
  - ...and so on.

## Expected Dimensions & Specifications
- **Recommended Size**: 128 x 128 pixels (or 256 x 256 pixels for high-density displays).
- **Format**: PNG with transparent background.
- **Aspect Ratio**: 1:1 (Square).
